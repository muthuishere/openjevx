# Report 16: licence-clean model 0.5.10 (and 0.5.8). Gate FAIL, not shipped

## What was built
- **0.5.8** (internal comparison only, never published).
  - Drops MS MARCO and the tasksource rows whose `license_use` is non-commercial or unspecified (per row,
    `finetuning/dataprep/licence.py`).
  - BGL weighted x3, plus a BGL gate slice.
  - 400,757 rows / 727,063 decisions. Vast $1.34 (cap $2).
- **0.5.10** (candidate for release v0.5.10).
  - Also drops loghub (BGL, HDFS), CodeSearchNet and the Devign/C-UDA defect set. Every kept and dropped source is cited
    in `licence-excluded.json`.
  - The loghub BGL slice is replaced by an EVAL-ONLY own-logs gate: 226 rows from our infrastructure logs, scrubbed,
    labelled by rule, hand check 40/40, never trained on, never published. Its limits come from shipped 0.5.2 on the
    same rows: >= 90% right & confident, <= 6% confidently wrong.
  - 302,473 rows / 628,779 decisions. Vast $1.12 (cap $1.50).
- All boxes were destroyed (`vastai show instances` empty).

## Decision
The gate failed, so per the brief: **not shipped, no second attempt.** The model, the run outputs and
`licence-excluded.json` are kept (local + private R2) as the record.

Options for the owner:
- (a) Find a log dataset whose licence explicitly allows commercial use, to replace loghub's normal-line coverage.
- (b) Accept the own-logs result as a named miss: the margin is 2.4 points, about 6 rows, mostly routine lines
  answered with less confidence, while the model catches more real failures.
- (c) Grow the own-logs gate as more CI failures and 5xx lines accumulate.

## Pipeline improvements made along the way
- Licence filter with per-row `license_use` and a cited manifest that travels with the run and the model archive.
- Generic gate slices with their own limits in config.
- The gate server is capped at 6 threads.
- `vast.py` now:
  - replaces a box that says running but never uploads its first log (a host that never ran our onstart cost $0.14);
  - skips hosts whose bandwidth costs over $0.01/GB (one smoke host billed $0.16 of bandwidth);
  - labels boxes `openjevx-<version>-DESTROY-AFTER`.
